# ABC Executive Summary and Profitability Dashboard

## Project Overview
An interactive Excel dashboard developed to analyze sales performance, revenue, and profitability. This project transforms sales data into meaningful visual insights using KPI cards, charts, Pivot Tables, and interactive slicers.

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Gross Profit
- Gross Profit Margin
- Total Units Sold
- Total Orders
- Cost of Goods Sold (COGS)

## Dashboard Features
- Monthly revenue and gross profit analysis
- Top 5 countries by revenue
- Revenue share by sales channel
- Region-wise revenue comparison
- Country-wise revenue map
- Interactive filters for product category, country, and quarter

## Tools Used
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Slicers
- KPI Cards
- Data Visualization

## Skills Demonstrated
- Data Analysis
- Business Intelligence
- Dashboard Development
- Data Visualization
- Sales Performance Analysis

## Project Objective
To provide a clear overview of business performance and help users explore sales trends, profitability, and regional revenue distribution.
